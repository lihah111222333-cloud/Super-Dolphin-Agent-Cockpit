## Bug 记录

### BUG-1：模板 DAG 草案预览最终输出未渲染占位符

复现步骤：
1. 打开 `http://127.0.0.1:5175`。
2. 进入“自动化”。
3. 点击“查看模板”。
4. 任意选择一个模板，例如“宣传视频”。
5. 查看右侧/下方 “DAG 草案预览”的“最终输出”。

实际结果：
- 宣传视频显示 `{{output_path}}final.mp4`。
- 其他模板显示 `{{output_path}}final.{{output_format}}`。

期望结果：
- 应使用当前表单值渲染，例如 `reports/workflows/government_enterprise_promo_video/{{run_id}}/final.mp4`。
- 如果预览声明为 DAG 草案，建议直接使用 `workflowTemplates/renderDag` 的渲染结果，避免前端本地预览与后端模板渲染逻辑不一致。

定位线索：
- `frontend-app/src/pages/workflows/WorkflowPage.jsx` 中 `EnterpriseTemplatePreview` 直接读取 `template.final_output.path_template`。
- 同文件已导入 `renderWorkflowTemplateDraft`，但模板详情页未调用该 RPC。

影响：
- 用户在模板页看到的最终交付路径不可信。
- 前端预览无法覆盖后端 `workflowTemplates/renderDag` 渲染差异，模板实现问题可能到 DAG 设计器阶段才暴露。

## 未覆盖
