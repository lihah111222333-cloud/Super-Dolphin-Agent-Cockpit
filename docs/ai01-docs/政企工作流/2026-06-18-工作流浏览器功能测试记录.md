## 发现的问题

### P3：模板子页面的页面状态文本仍显示为自动化

修复状态：已修复。回归测试覆盖 `查看模板` 后当前页面状态显示为 `当前页面: 模板`，点击 `返回自动化` 后恢复为 `当前页面: 自动化`。

现象：进入模板库后，页面主标题已经是 `模板`，模板库也独立显示，但 DOM 可访问性文本中仍存在：

```text
当前页面: 自动化
```

影响：普通视觉使用不受影响，但屏幕阅读器或依赖页面状态文本的自动化测试可能会把模板子页面误判为自动化主页。

复现步骤：

1. 打开 `http://127.0.0.1:5175/`。
2. 点击左侧 `自动化`。
3. 点击 `查看模板`。
4. 观察 DOM/可访问性快照，页面标题为 `模板`，但状态文本仍是 `当前页面: 自动化`。

建议：如果模板页是自动化模块内的子视图，可以考虑将状态文本改成 `当前页面: 模板` 或 `当前页面: 自动化 / 模板`，避免和可见标题不一致。
