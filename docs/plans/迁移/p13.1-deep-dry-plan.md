# P13.1 深度 DRY 计划 — 10 Agent 全仓扫描后的二级+一级补充

> 生成时间：2026-04-04
> 前提：P13 W1（守卫+死代码）+ W2（provider+orchestration factory.go）+ W3（skill+uistate factory.go）已完成
> 来源：10 个 DRY 深度扫描 Agent（scan-1~10）报告
> 核心目标：消灭剩余 ~150 处二级 DRY + ~13 组跨包一级 DRY

---

## 0. 执行策略

```
先做二级（包内 factory.go）→ 再做一级（shared 提升）
每包一个 factory.go，收敛包内所有重复模式
抽取铁律：迁移 + 删旧 + 改调用 + 零残留
```

**factory.go 守卫**：≤800 行、不计入包文件数/包总行数、单函数 ≤80 行、CC ≤10
