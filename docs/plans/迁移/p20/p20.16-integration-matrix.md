## 7. 风险与实现注意点

1. **不要把 `1bb2a00` 误判成“前端已覆盖”**：当前前端只用 legacy `skills/list` / `skills/match/preview`，与 `skill/list` / `skill/expand` 不是同一条链。
2. **不要把 `composer-bar.behavior` 误判成 FG-2 已闭环**：它只测 legacy selector 显隐，没有验证 `UnifiedChatPage` 真的 mount `<LaunchSkillPicker>`。
3. **不要只测 `applyLaunchSkillSelection()` 纯函数就声称 B2-3 完成**：真正风险在 launch skills 穿过 thread/prompt/provider 边界时被丢。
4. **Bug #1 仍需保留运行时 PoC 思路**：§10.24 的 detector 类 false-positive 历史已经发生过，后续若再改 fallback detector，必须保留 runtime import 级验证。
5. **p20.13 未落地前不要把 approval cache 混入本单矩阵**：本页先收敛到与 `0b4ad39/1bb2a00/78f26de/472756c/3283734/78c6907/cec26fe/b0d2555` 直接相关的终验路径。
