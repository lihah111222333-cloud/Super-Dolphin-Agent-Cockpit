### 6.1 手工 checklist（UI + CLI 日志）
- UI：无 thread 时选择 launch skills 后首次发送，`thread/start` 成功且后续 `turn/start` 仍保留相同 skill 语义。
- UI：codex / claude 两个 provider 都跑一遍相同 smoke，确认 launch picker、send path、history 恢复一致。
