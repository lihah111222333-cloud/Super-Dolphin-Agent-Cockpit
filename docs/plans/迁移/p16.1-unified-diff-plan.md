## 0. 归一架构

```
Codex: session → toolbridge.routeToolCall → peer → mcp-lsp
Claude: CLI → proxy /mcp/<family>/<agentId> → toolbridge.routeToolCall → peer → mcp-lsp

                        toolbridge.routeToolCall（统一入口）
                        ├── 知道 agentId（Codex 从 req 拿，Claude 从 URL path 拿）
                        ├── replace_range/rename: before 读文件 → 执行 → after 读文件 → diff
                        ├── bus.Publish(ToolDiffUpdated)
                        └── 转发结果返回调用方
```

### 1.2 主进程 proxy server

**新建** `internal/platform/toolbridge/proxy.go`：

```go
// ServeProxy 启动 MCP HTTP proxy
// 监听 /mcp/<family>/<agentId> 路径
// 解析 family + agentId → 构造 ToolCallRequest → 调用 routeToolCall
func (h *Handler) ServeProxy(ln net.Listener) error  // v10：参数改为 net.Listener，与启动代码一致

// handleProxyRequest 处理单个 MCP JSON-RPC 请求
// 支持：
//   - initialize → proxy 本地应答（不转发 peer，因为 peer 只接 tools/list + tools/call）
//   - tools/list → 按 family 分发 listPeerTools
//   - tools/call → 走 routeToolCall（带 diff tracking）
func (h *Handler) handleProxyRequest(w http.ResponseWriter, r *http.Request)
```

**各 method 处理逻辑**（v10 补全）：

| MCP method | 处理方式 | 说明 |
|------------|----------|------|
| `initialize` | **proxy 本地应答** | 返回 `{protocolVersion: "2025-11-25", capabilities: {tools: {}}, serverInfo: {name: "proxy", version: "1.0.0"}}` — peer callback 只接 `tools/list` + `tools/call`，不识别 `initialize` |
| `notifications/initialized` | 忽略（notification） | Claude CLI 发送的初始化完成通知，无需响应 |
| `tools/list` | **按 family 分发** | 从 URL path 取 family，调用 `h.listPeerTools(ctx, clientKind)` |
| `tools/call` | **走 routeToolCall** | 构造 ToolCallRequest（带 agentId/threadId/callId），包含 diff tracking |
| 其他 | 返回 MCP error | `{code: -32601, message: "method not found"}` |

**tools/list 闭环**：
- family=lsp → `h.listPeerTools(ctx, dto.ClientKindLSP)`（handler.go:116-132）
- family=orch → `h.listPeerTools(ctx, dto.ClientKindOrch)`（handler.go:116-132）
- 每个 family 独立返回自己的工具列表，不会重复

**tools/call 结果适配**（v10 补全）：
- `routeToolCall` 返回 `*ToolCallResult`，包含 `ContentItems []ToolCallContentItem`
- proxy 需要将其转换为 MCP JSON-RPC response 格式：
```go
// proxy.go 内部：
result, err := h.routeToolCall(ctx, toolReq)
if err != nil {
    // 返回 JSON-RPC error
    writeJSONRPCError(w, reqID, -32603, err.Error())
    return
}
// 转换为 MCP tools/call response
writeJSONRPCResult(w, reqID, map[string]any{
    "content": toMCPContent(result.ContentItems),
    "isError": !result.Success,
})
```
- `toMCPContent` 将 `ToolCallContentItem.Type="inputText"` 映射为 MCP `{"type":"text","text":"..."}`

**proxy 启动**（toolbridge/module.go）：
- `atomic.Value` 存 proxyAddr，`fx.Provide` 导出 `func() string` 闭包
- OnStart：`net.Listen("tcp","127.0.0.1:0")` → 失败 return err 阻断 fx → `go h.ServeProxy(ln)`
- claudecli/driver 注入 `func() string`，调用时才读取实际地址

### 1.3 Codex agentId 透传

- **handler.go:71-74**：peer.Callback payload 补充 `_agentId`/`_threadId`/`_callId`
- **cmd/mcp-lsp/fx.go:57-64**：OnToolsCall 解析这些字段用于日志/审计
- diff tracking 不在 peer 内做，在主进程 toolbridge 做

### 1.4 Claude proxy 的 threadId/callId 回填

- **threadId**：`bindingStore.GetThreadByAgent(ctx, agentID)` → `(string, error)`（contract.go:17，store.go:138-144）
  - 查询失败不阻断工具调用，threadID 留空，仅影响 diff 展示
- **callId**：JSON-RPC `id`（`json.RawMessage`）→ `fmt.Sprintf("%v", id)` 兼容 string/number
- **Handler 依赖**：新增 `bindingStore bindingstore.Store` 字段，fx 注入

### 1.5 diff tracking

- routeToolCall 内对写盘工具（replace_range/rename）做 before/after 文件快照
- 流程：`shouldTrackDiff` → `difftracker.BeginSnapshot(cwd)` → 执行 → `difftracker.EmitGitDiff(snapshot)` → `h.emitter(DiffResult{...})`
- **直接复用保留的 difftracker 核心**：BeginSnapshot / EmitGitDiff / git_ops，无需重写
- `h.emitter` 复用现有 `provideDiffEmitter`（module.go:72-89）→ `event.Publish(ToolDiffUpdated)`
- uistate projector 已订阅 `ToolDiffUpdated`，无需改动
- 新增文件：toolbridge/diff_gen.go（仅 `shouldTrackDiff` 判断 + 调用 difftracker 核心的胶水代码）

## 4. 审查迭代摘要

共经 4 轮审查（v7→v8→v9→v10→v11），累计修正 19 项，核心决策：

| 决策 | 版本 | 说明 |
|------|------|------|
| driver 只传 ProxyHTTPAddr，不传 PeerHTTPAddrs | v9 | 强制 Claude 走 proxy，封死直连绕过 |
| threadId 用 GetThreadByAgent | v9 | Binding 无 ThreadID 字段，用现成 SQL 查询 |
| proxyAddr 延迟绑定 func() string | v9 | OnStart 后才有地址，避免时序问题 |
| OnStart 失败 return err | v10 | 封死 sidecar 降级场景 |
| initialize proxy 本地应答 | v10 | peer 只接 tools/list+tools/call |
| difftracker 保留核心删旧链路 | v11 | 保留 git_diff/git_ops/types/resolver，删 aggregator/unified/tool_context/hooks |
| callId 用 json.RawMessage | v11 | 兼容 string/number |
