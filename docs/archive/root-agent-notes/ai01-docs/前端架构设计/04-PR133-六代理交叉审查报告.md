```txt

```

`App.jsx` 冲突点包括：

- main 侧新增或保留了 `AppUpdateBanner` 与 `checkAppUpdate/installLatestAppUpdate` 相关逻辑。
- 本分支新增了 `React.lazy` / `Suspense` 页面级 code splitting。
- 本分支新增了 `useShallow(selectAppShellStore)` selector 收窄。

解决冲突时不能简单取一边：

- 必须保留 main 的更新提示入口，否则会回退已有功能。
- 必须保留本分支的 lazy loading 和 selector 收窄，否则 Phase 4 目标会被撤销。
- `App.test.jsx` 需要同时保留 main 新增测试和本分支为 lazy loading 调整的 `findBy*` 异步断言。
