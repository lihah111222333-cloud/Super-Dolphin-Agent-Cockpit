# 修改记录 06-13 14:08

## 需求

本次围绕数据源上传和 RAG 文本拆块补充后端能力：

- 在 `internal/module/rag` 下新增文本拆块能力，用于把 `.txt` 文本按约 500 token 一段切分。
- 拆块时优先在 500 token 附近寻找句读符号作为分割点，例如 `。`、`？`、`！`、`,`、`，` 等。
- 如果 500 token 附近找不到合适符号，则直接按 500 token 截断，避免无限扩展或静默跳过。
- 调整 `datasource/upload` RPC 参数，只接收 `sourcePath`，不再由调用方传入 `cwd`。
- 新增一个 RPC 接口，用于读取 `.agent/datasources/uploads` 目录下的所有数据源文件名。

## 修改内容

### RAG 文本拆块模块

- 新增 `internal/module/rag/chunker.go`
  - 增加文本拆块入口方法。
  - 默认目标块大小为 500 token。
  - 在目标 token 附近寻找优先分割符号。
  - 找到符号时在符号结尾处分块，尽量保证语义完整。
  - 找不到符号时直接按目标 token 位置分块，满足“500 token 附近没有入口点就直接拆 500 token”的要求。
  - 对空文本、空白文本和连续长文本做显式处理。

- 新增 `internal/module/rag/chunker_test.go`
  - 覆盖按标点分块的路径。
  - 覆盖没有标点时按目标大小硬切的路径。
  - 覆盖空文本和短文本场景。

### 数据源上传参数调整

- 修改 `internal/module/datasource/service.go`
  - `UploadFileRequest` 只保留 `sourcePath`。
  - 上传目录固定为当前项目工作目录下的 `.agent/datasources/uploads`。
  - 继续保留上传后缀限制、文件存在冲突检查、写入失败清理等行为。

- 修改 `internal/module/datasource/rpc.go`
  - `datasource/upload` RPC 继续使用严格参数解析。
  - 调用方传入 `cwd` 等多余字段时会被拒绝。
  - 上传参数收敛为：

```json
{
  "sourcePath": "要上传文件的绝对路径"
}
```

### 数据源文件列表接口

- 修改 `internal/module/datasource/service.go`
  - 新增读取上传目录文件名的方法。
  - 只返回普通文件名，不返回子目录。
  - 文件名按字典序排序，保证结果稳定。
  - 上传目录不存在时返回空列表。

- 修改 `internal/module/datasource/rpc.go`
  - 新增 RPC 方法 `datasource/list`。
  - 返回 `.agent/datasources/uploads` 目录下的数据源文件名列表。
  - 返回结构为：

```json
{
  "fileNames": [
    "example.pdf",
    "notes.txt"
  ]
}
```
