## 4. P0 整改清单

1. 给前端跨语言合同增加类型边界。

   最小做法：添加 `jsconfig.json`，打开 `checkJs` 的渐进计划，先覆盖 `shared/api` 和 `entities/client/model`。更彻底的做法是把 `backendApi.js`、`providerPreferences.js` 和核心 DTO helper 迁到 TypeScript。

2. 固化 P0 RPC 的三端合同。

   对 `thread/start`、`turn/start`、`approval/respond`、provider preference、DAG mutation、memory mutation 建立矩阵：前端 facade、consumer test、Go handler、strict decode、provider side effect 均可追踪。

3. 跑一次 Windows 真实桌面链路。

   用 `D:\project\Super-Dolphin-worktrees\ui-refactor-integration-20260613\run-new-ui-desktop.ps1` 启动，浏览器访问 `http://127.0.0.1:5175/`，至少手测 chat、workflow、files、skills、memory、settings。记录端口、backend readiness、Vite readiness、Wails bridge 是否正常。

4. 明确 provider 产品口径。

   在 README/设置页/审查报告里保持一致：当前桌面主链路是 Codex runtime。若要恢复 Claude，单独做功能分支和端到端验证，不要通过兼容命名暗示已支持。

## 5. P1 整改清单

1. 分批拆 `useClientStore.js`。

   第一批建议拆：

   - provider preference 读取和验证
   - bridge event revision patch
   - thread lifecycle action
   - runtime result buffer
   - warning/log sink

2. 分批拆 `ChatPage.jsx`。

   第一批建议拆：

   - composer controller
   - timeline materialization wiring
   - runtime panel state wiring
   - project/thread rail interaction

3. 稳定 CSS 组织。

   当前已经拆成 45 个 CSS 文件，后续重点是减少顺序耦合。建议在 `main.jsx` 的 CSS import 区块标注 base、app shell、page、component、polish、late 的分组规则，并给核心页面保留样式回归测试。

4. 对 `backendApi.contractMatrix.js` 增加后端对账。

   新增只读检查脚本，扫描 Go RPC registration 和 `RPC_METHODS`，找出缺失 facade、缺失 matrix、缺失测试归属的项目。

## 6. P2 整改清单

1. 文档口径收敛。

   保持 README、AGENTS、CLAUDE、codemap 对以下事实一致：

   - Go 版本是 `1.25.7`。
   - 当前主 UI 是 `frontend-app`。
   - `cmd/agent-terminal/frontend` 是 legacy/embed 路径。
   - 当前桌面主 provider 是 Codex。

2. 拆大测试文件。

   `App.test.jsx` 和 `useClientStore.test.js` 行数过大，建议按 bootstrap、provider preference、thread lifecycle、timeline、memory badge、settings 等主题拆成小文件。

3. 明确 legacy UI 生命周期。

   如果 legacy Vue 只保留 embed dist 或兼容测试，应写清楚停用边界；如果还要维护，则需要明确它与 `frontend-app` 的职责分割。

4. 文档编码检查。

   统一中文文档编码策略，避免 Windows PowerShell 输出乱码影响代理读取。

## 7. 建议执行顺序

1. 先跑当前 UI 全量前端验证：`npm run lint && npm test && npm run build`。
2. 再跑桌面真实启动：`.\run-new-ui-desktop.ps1`，手测主页面。
3. 然后做类型边界和 P0 RPC 合同收敛。
4. 最后按小步移动方式拆 store/page/CSS，不把行为变更混入移动提交。
