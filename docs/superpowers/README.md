# Superpowers Planning Archive

This directory contains Superpowers design specs and implementation plans.

- `specs/` records approved designs and should be read only when a task relates
  to that feature or design history.
- `plans/` records historical implementation plans and is not current
  implementation truth unless the user explicitly asks to execute or audit a
  specific plan.

For current repository behavior, prefer source code, tests, accepted ADRs, and
contract docs.
