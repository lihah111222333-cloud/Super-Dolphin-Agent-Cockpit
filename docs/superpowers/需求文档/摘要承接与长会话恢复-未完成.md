## 推荐第一版产品形态

### 系统自动处理

- 自动记录会话历史、cwd、模型、权限模式、runtime config、prompt snapshot 和关键产物。
- 自动记录最近涉及的文件、命令、验证结果和失败原因。
- 自动监控 context usage，在接近风险阈值时提示用户。
- 在会话退出、继承会话或恢复前，自动生成 harness 侧承接材料草稿。
- provider 支持 compact 时，系统展示 compact 可用状态和结果，但不宣称这是 Super-Dolphin 自研压缩。

### 用户显式操作

- 手动生成或刷新摘要。
- 手动触发 provider compact。
- 从当前会话创建继承会话。
- 从产物或 shared file 继续对话。
- 在恢复现场前查看并确认承接摘要。
- 当 provider compact 失败或不支持时，选择新会话承接或清理上下文。

### 不建议第一版自动处理

- 不自动替用户切换到新会话。
- 不在用户无感知情况下丢弃关键历史。
- 不把摘要静默塞入模型上下文而完全不可见。
- 不把 provider compact 失败包装成成功。

## 概念边界

### 摘要

摘要是 harness 侧承接材料，用于描述目标、现状、已完成、未完成、关键文件、命令、风险和下一步。摘要可以给用户看，也可以作为新会话 seed instructions 的一部分。

### Provider compact

Provider compact 是上游 provider 自己提供的上下文压缩能力。Super-Dolphin 只负责触发、展示状态、记录结果和处理失败，不宣称自己具备模型级压缩。

### 继承会话

继承会话是从旧会话创建新会话，并带入必要承接材料、项目路径、runtime config、关键产物和摘要。它不是继续同一个 provider session。

### 恢复现场

恢复现场是重新打开旧会话或从旧会话继续工作，重点恢复用户视角的项目、会话、产物、上下文提示和下一步建议。

### 候选方向：继承会话

这些方向需要调研后再确定是否进入第一版：

- 从当前会话新建继承会话。
- 从 shared file / final output 新建继承会话。
- 新会话启动后自动发起 kickoff，让 Agent 复述上次进展和下一步建议。

### 候选方向：长会话恢复

这些方向需要和现有 provider/thread 能力核对：

- provider session resume。
- prompt snapshot 复用。
- runtime config 复用。
- context usage 状态恢复。
- 自动续接失败重试。

## 当前项目现状

- `useSummaryHandoff.js` 已有摘要转 seed instructions 的工具，但注释明确 Phase 2a 是截断式兜底，后续需要 `thread/summarize` RPC。
- `thread.Compact` 已支持 provider compact 适配，但这是 provider 能力，不是产品自带模型级压缩能力；token 结果仍是估算。
- ContextUsageBanner 已有触发 provider compact、新建继承会话、自动续接失败提示。

## 不做

- 不重写 provider session 管理。
- 不重写 memory 存储。
- 不把 DAG 的节点级上下文预算纳入本需求。
- 不自研模型级上下文压缩能力；只适配 provider compact 或通过 harness 侧承接材料缓解长会话问题。

## 前端验收标准

- 完成 Hermes 和同类产品调研后，输出明确的长会话承接交互方案。
- UI 方案能说明：什么时候提示、提示什么、用户能点什么、系统会自动做什么。
- UI 方案能区分摘要、provider compact 适配、继承会话、恢复现场这几个概念。
- 第一版应至少提供：手动摘要、恢复入口、继承会话入口、provider compact 状态展示、承接摘要预览。

## 后端/API 验收标准

- 完成现有链路核对，明确哪些能力已有、哪些需要新增。
- 明确是否需要 harness 侧 `thread/summarize` 或等价 RPC；该 RPC 不能被描述为模型级上下文压缩能力。
- 明确摘要接口是否需要读取 timeline、tool result、plan、shared files、final outputs。
- 明确摘要结果是作为 base instructions、shared file 承接材料，还是独立上下文对象。
- 第一版应至少能保存和读取恢复现场所需的会话元数据、摘要草稿、关键产物和 provider compact 状态。
