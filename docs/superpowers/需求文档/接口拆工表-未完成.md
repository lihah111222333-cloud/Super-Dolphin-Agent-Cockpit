# 接口拆工表需求（未完成）

## 状态

未完成。本文先按产品模块列出第一版接口，便于前后端和后台同事拆任务。接口路径是草案，最终需与现有 RPC/HTTP 风格对齐。

## 拆工原则

- P0 接口服务演示链路和 MVP 主链路。
- 客户端不直接请求上游 provider。
- 账号权益、模型权限和用量都由服务端返回。
- 后台接口必须有管理员鉴权和审计。
- 支付回调和用量扣减必须幂等。

## 技术注意事项

- 所有 P0 客户端接口需要返回用户可理解错误码。
- 支付回调不能依赖前端确认。
- 模型请求和用量扣减必须有请求 ID。
- 重试不能产生重复扣费。
- 后台手动操作必须写审计日志。
- 演示环境的模拟支付接口必须不能进入生产环境。

## 验收标准

- 技术同事能按接口表拆前端、后端、后台、网关四类任务。
- P0 接口覆盖试用、登录、充值、模型请求、用量刷新、产物、恢复会话。
- 后台 P0 接口覆盖账号、订单、用量、模型、路由、token 池。
- 每个 P0 接口都有明确前端使用位置。
