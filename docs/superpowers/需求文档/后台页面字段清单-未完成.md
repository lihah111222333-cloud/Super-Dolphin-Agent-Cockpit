# 后台页面字段清单需求（未完成）

## 状态

未完成。本文用于把支付后台和运营后台拆到页面与字段级，方便技术同事估算接口、表结构和前端页面工作量。

## 后台范围

- 账号管理。
- 订单管理。
- 用量流水。
- 模型管理。
- 模型路由。
- 上游 token 池。
- 管理员操作审计。
- 基础看板。

## 页面清单

### 1. 账号列表

字段：

- 账号 ID。
- 账号名。
- 登录状态。
- 试用状态。
- 当前余额。
- 套餐状态。
- 可用模型数量。
- 账号状态：正常、限流、冻结。
- 注册时间。
- 最近登录时间。
- 最近请求时间。

操作：

- 查看详情。
- 冻结账号。
- 解冻账号。
- 手动调整额度。
- 查看用量流水。
- 查看订单。

### 2. 账号详情

字段：

- 基本信息：账号 ID、账号名、创建时间、状态。
- 权益信息：余额、套餐、试用额度、模型权限、功能开关。
- 设备信息：设备标识、最近登录时间、最近 IP。
- 最近订单。
- 最近用量。

操作：

- 增加额度。
- 扣减额度。
- 调整模型权限。
- 冻结或解冻。
- 添加备注。

### 3. 订单列表

字段：

- 订单 ID。
- 账号 ID。
- 商品名称。
- 支付金额。
- 到账额度。
- 支付渠道。
- 订单状态：待支付、成功、失败、关闭、退款。
- 创建时间。
- 支付时间。
- 回调状态。

操作：

- 查看详情。
- 手动补单。
- 标记退款。
- 查看回调日志。

### 4. 订单详情

字段：

- 订单基础信息。
- 支付渠道流水号。
- 回调原始状态。
- 幂等处理结果。
- 额度生效流水。
- 异常原因。
- 管理员备注。

### 5. 用量流水

字段：

- 流水 ID。
- 账号 ID。
- 会话 ID。
- 请求 ID。
- 展示模型名。
- provider。
- 真实模型名。
- 输入 token。
- 输出 token。
- 模型倍率。
- 预扣额度。
- 实扣额度。
- 上游 usage 原始值。
- 请求状态。
- 错误分类。
- 创建时间。

操作：

- 按账号筛选。
- 按模型筛选。
- 按 provider 筛选。
- 导出。
- 查看请求详情。

### 6. 模型管理

字段：

- 展示模型名。
- 模型分层：基础、高级、旗舰。
- 是否可见。
- 是否启用。
- 是否允许试用。
- 是否需要登录。
- 是否需要充值。
- 消耗倍率。
- 单次最大消耗。
- 排序。

操作：

- 新增模型。
- 编辑模型。
- 启用或禁用。
- 调整倍率。

### 7. 模型路由

字段：

- 展示模型名。
- provider。
- 真实模型名。
- 路由优先级。
- 权重。
- 状态。
- 失败率。
- 平均延迟。
- 最近调用时间。

操作：

- 调整优先级。
- 启用或禁用路由。
- 绑定 token 池。

### 8. 上游 token 池

字段：

- token 标识。
- provider。
- 状态：启用、禁用、冻结、异常。
- 剩余额度或限额。
- 今日调用次数。
- 今日错误次数。
- 错误率。
- 最近错误。
- 最近使用时间。
- 创建时间。
- 备注。

操作：

- 新增 token。
- 禁用 token。
- 启用 token。
- 标记异常。
- 查看调用记录。

### 9. 操作审计

字段：

- 管理员账号。
- 操作类型。
- 操作对象。
- 操作前值。
- 操作后值。
- 操作原因。
- 操作时间。
- 请求 IP。

## 基础看板

指标：

- 新增账号。
- 活跃账号。
- 充值金额。
- 消耗额度。
- 请求次数。
- 请求失败率。
- 异常 token 数。

## 验收标准

- 后台至少能完成账号、订单、用量、模型、路由、token 池查询。
- 手动调整额度必须记录原因和审计日志。
- 上游 token 不展示完整明文。
- 模型倍率、可用状态、试用权限可配置。
- 账号详情能追溯余额来源和消耗去向。
