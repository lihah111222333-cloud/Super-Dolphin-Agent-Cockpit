# 发布验收清单需求（未完成）

## 状态

未完成。本文用于定义“演示可通过”和“MVP 可上线”的检查项，避免功能散落但主链路跑不通。

## 验收分级

### 演示可通过

适合产品面试、内部路演或给技术同事对齐方向。允许部分支付、后台和上游模型使用模拟数据，但主流程必须真实可操作。

### MVP 可上线

适合小范围真实用户使用。账号、权益、网关、扣费和后台必须真实闭环。

## 演示可通过清单

### 账号与试用

- 未登录可以进入试用工作台。
- 试用态只能选择基础模型。
- 登录入口清晰可见。
- 登录后账号菜单展示账号和剩余用量。
- 退出登录后回到试用态。

### 模型与充值

- 模型列表展示基础、高级、不可用状态。
- 未解锁模型可见但不可用，并提示充值或升级。
- 支持模拟充值或后台手动加额度。
- 充值后客户端刷新用量和模型权限。

### 主工作台

- 能新建或打开项目。
- 能创建会话并发起任务。
- 能展示 Agent 执行状态、工具调用和结果。
- 能查看产物。
- 能从产物或会话继续对话。

### 长会话承接

- 有恢复入口。
- 有继承会话入口。
- 有摘要或承接材料预览。
- 能说明 provider compact 和 harness 摘要的边界。

### 后台演示

- 能查看账号列表和账号详情。
- 能查看订单或模拟订单。
- 能查看用量流水。
- 能查看模型路由和 token 池状态。
- 能手动调整额度并留下记录。

## MVP 可上线清单

### 账号系统

- 登录态可持久化。
- session/token 失效时前端能进入试用态或重新登录。
- 权益接口可返回试用、余额、模型权限、功能开关。
- 账号冻结后模型请求被阻断。

### 支付与订单

- 可创建订单。
- 支付回调幂等。
- 充值成功后额度生效。
- 退款或异常订单有处理入口。
- 订单状态和额度流水一致。

### 模型网关

- 客户端所有模型请求经过网关。
- 客户端不暴露上游 token。
- 网关能校验账号权益、余额和模型权限。
- 网关能记录 usage、倍率、扣费和错误。
- 上游失败时能释放预扣或回滚。

### 运营后台

- 账号、订单、用量、模型路由、token 池可查询。
- 可禁用模型、provider 或 token。
- 可手动调整额度。
- 管理员操作有审计记录。

### UI

- 主工作台不是后台菜单集合。
- 账号、模型、用量、充值、产物、恢复入口在主流程可见。
- 普通用户能完成：试用、登录、充值、选模型、发任务、看结果、恢复会话。

## 失败条件

- 客户端需要用户配置上游 token 才能跑主流程。
- 未登录试用能使用高级模型。
- 充值成功后客户端不能刷新权益。
- 上游 token 出现在客户端响应、日志或前端状态。
- 模型请求失败后仍扣费且没有回滚记录。
- 后台无法查账号用量和订单。
- 长会话恢复只能靠用户手动复制粘贴历史内容。
