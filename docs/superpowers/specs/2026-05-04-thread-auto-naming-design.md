# 线程自动命名设计

> 日期: 2026-05-04
> 状态: 待审阅

## 背景

当前线程创建时，`thread.Name` 默认为空，前端 fallback 到线程 ID（`agent_<纳秒时间戳>`），侧边栏显示类似 `agent_17778825480336...`，完全不可读。

## 目标

让每个对话在侧边栏都有一个 ≤ 8 个显示单元的可读标题，零 LLM 成本，纯 harness 侧实现。

## 设计

### 1. 默认命名

**时机**：线程创建时。

**规则**：如果 `displayName` 为空，设为 `对话 #N`。

**N 的计算**：创建时刻已有线程总数 + 1。仅用于显示，不要求连续（删除线程后允许跳号）。

**实现位置**：`internal/module/thread/spawn.go` 的 `persistStartedSession` 阶段。

### 2. 自动提取标题

**时机**：首条用户消息到达时触发提取，直接赋值 `thread.Name`，不走 RPC。如果线程先创建为"待启动"状态，创建时显示 `对话 #N`，消息到达后更新。

**计量单位**：≤ 8 个显示单元。1 个中文字 = 1 单元，1 个英文单词 = 1 单元。例：`订单表 JOIN 优化` = 6 单元，`spawn.go race condition` = 3 单元。

**提取规则**（纯字符串处理，无 LLM）：

1. 去 `@mention` — `@头脑风暴，订单表优化` → `订单表优化`
2. 去寒暄/指令前缀 — `帮我`、`请`、`能不能`、`你`、`看看`、`我想`、`一下` 等
3. 去代码块 — 反引号包裹的内容整块跳过
4. 取第一句实质内容 — 按句号/问号/感叹号/逗号/换行分句，取首句
5. 提取技术词 + 名词 + 动作，丢弃虚词。技术词识别规则：
   - 含 `.` → 文件名（如 `spawn.go`、`index.ts`）
   - 含 `_` 或驼峰命名 → 函数/变量名（如 `SetName`、`thread_store`）
   - 含 `/` → 路径（如 `internal/module`）
   - 纯 ASCII 大写词 → 术语/缩写（如 `JOIN`、`RPC`、`SQL`）
   - 其余英文单词保留，中文虚词（的、了、吧、啊、呢）丢弃
6. 截断 ≤ 8 个显示单元 — 超出部分直接丢弃，不加省略号
7. 兜底 — 提取结果 ≤ 2 个显示单元或全是代词 → 保持 `对话 #N`

**跳过条件**：如果 `thread.Name` 已被用户手动 rename 过，不覆盖。判定方式：线程增加 `manuallyRenamed bool` 字段，`SetName` RPC 被调用时置为 true。

**实现位置**：`internal/module/thread/` 下新建提取函数，首条消息到达时调用，赋值 `thread.Name` 并持久化。

**效果预估**：

| 类型 | 占比 | 示例 |
|------|------|------|
| 精准 | ~60% | `订单表 JOIN 优化` |
| 还行 | ~20% | `用户点保存后 RPC` |
| 不准 | ~15% | `昨天看那个 PR` |
| 兜底 | ~5% | `对话 #7` |

### 3. 续对话命名

**触发场景**："创建并继续"（上下文耗尽时分裂新对话）。

**命名规则**：

- 第 1 次续：`原标题 (续)`
- 第 N 次续（N ≥ 2）：`原标题 (续 N)`

续对话标题允许超过 8 单元限制 — 后缀是系统加的，不算在提取长度内。

**实现位置**：在"创建并继续"逻辑中，读取父线程 `thread.Name`，拼接后缀赋给新线程。

## 不做的事

- 不加 LLM 调用生成标题
- 不改 system prompt
- 不加 MCP tool
- 不改线程 ID 生成逻辑（内部仍为 `agent_<timestamp>`）
- 不做 badge 展示改造

## 数据流

```
线程创建
  │
  ├─ displayName 为空？ → 设为 "对话 #N"
  │
首条用户消息到达
  │
  ├─ thread.Name 被手动 rename 过？ → 跳过
  │
  ├─ 提取 prompt 关键词 → ≤ 8 显示单元
  │    ├─ 提取成功 → 更新 thread.Name
  │    └─ 提取失败（太短/代词） → 保持 "对话 #N"
  │
"创建并继续"
  │
  └─ 新 thread.Name = 父标题 + " (续)" / " (续 N)"
```
