# 开发中文档

本目录只保存有明确结束条件的提案和执行计划，不属于当前实现事实。

## 目录

- [proposals](proposals/)：可供评审、尚未接受的设计提案。
- [plans](plans/)：已经批准、仍在执行的实施计划。

## 生命周期

1. 提案被接受后，应转化为 ADR、契约、架构文档或执行计划。
2. 提案被拒绝、撤回或替代后，移动到 `docs/archive/plans/`。
3. 执行计划完成、取消或被替代后，移动到 `docs/archive/plans/`。
4. 本目录中的文档必须注明状态、负责人、创建日期和退出条件。

源码、测试和已接受的 ADR、契约仍是当前行为的事实来源。
