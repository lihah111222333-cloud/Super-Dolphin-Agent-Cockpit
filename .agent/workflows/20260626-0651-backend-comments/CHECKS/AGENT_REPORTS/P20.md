- `file(diagnostics/open_file)`：读取诊断并确认测试清单无 LSP 语法/类型诊断。
- `inspect(definition)`：定位 `ParseAutomationConfig` 定义，确认测试注释对应当前实现入口。
- `completion`：在测试上下文补充符号候选，复核当前文件 LSP 服务可用。
