# 风险登记

| 风险 | 触发条件 | 缓解 |
|---|---|---|
| 机械注释污染 | 注释只复述函数名或代码行 | worker 必须解释职责、约束或失败边界；父任务抽查 diff |
| 并行写冲突 | 多 worker 修改同一文件 | `PARTITIONS/Pxx.files` 互斥；禁止跨分区编辑 |
| 生成代码漂移 | worker 修改 `Code generated` 文件 | 生成文件排除在分区外；发现缺口只报告 |
| 验证成本过高 | 每个文件守卫耗时过长 | worker 只改高价值缺口；每个已改文件仍必须跑单文件守卫 |
| 业务行为误改 | 注释编辑误碰代码 | diff 审查只接受注释/gofmt 相关变更 |
| 包级 guard 变化 | 添加注释导致文件行数超限 | 单文件守卫即时发现；必要时收窄注释或拆已有过长函数另行报告 |
| MCP 生命周期工具不可见 | 子代理会话未暴露 `task_*` 工具 | worker 报告不可用，父任务用本工作流文件维护状态 |
