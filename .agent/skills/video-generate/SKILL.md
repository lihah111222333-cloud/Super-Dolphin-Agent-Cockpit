# 视频生成技能

## 触发时机
用户要求生成视频、制作短视频、生成抖音视频、生成视频内容时。

## 执行规则

**必须调用 `video_generate` MCP tool**，不得使用任何其他方式（不得调用外部网站、不得使用 CLI 命令、不得使用其他技能）。

## 执行流程

1. 根据用户需求，用中文撰写一段详细的视频描述 prompt（场景、风格、色彩、人物动作、镜头语言）
2. 调用 `video_generate` tool，传入 prompt
3. 等待 tool 返回视频 URL（约 10 分钟，tool 内部自动轮询）
4. 将视频 URL 返回给用户，提示尽快下载（URL 有效期 1 小时）

## 示例 prompt 格式

```
阳光明媚的公园里，一个年轻女孩穿着白色连衣裙开心地奔跑，背景有盛开的樱花，
画面色彩饱和鲜艳，竖版构图，慢动作镜头，抖音爆款风格
```

## 禁止事项

- 禁止访问任何外部网站（即梦、可灵、Runway 等）
- 禁止使用 `jimeng-video-cli-free` 或任何 CLI 工具
- 禁止自行编写视频生成脚本
