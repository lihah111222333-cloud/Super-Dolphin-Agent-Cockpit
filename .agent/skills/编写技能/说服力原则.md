# 技能设计中的说服原则

## 概览

LLM 会响应与人类相同的说服原则。理解这种心理学有助于设计更有效的技能：不是为了操纵，而是为了确保关键实践即使在压力下也会被遵循。

**研究基础：** Meincke 等（2025）在 N=28,000 个 AI 对话中测试了 7 种说服原则。说服技巧让遵从率翻倍以上（33% → 72%，p < .001）。

## 七个原则

### 1. 权威
**含义：** 对专业知识、资历或官方来源的服从。

**在技能中的作用：**
- 命令式语言：“你必须”、“绝对不能”、“Always”
- 不可协商的框架：“绝无例外”
- 消除决策疲劳和合理化

**何时使用：**
- 强制纪律类技能（TDD、验证要求）
- 安全关键实践
- 已确立的最佳实践

**示例：**
```markdown
✅ Write code before test? Delete it. Start over. 绝无例外.
❌ Consider writing tests first when feasible.
```

### 2. 承诺
**含义：** 与先前行动、陈述或公开声明保持一致。

**在技能中的作用：**
- 要求声明：“Announce skill usage”
- 强制明确选择：“Choose A, B, or C”
- 使用跟踪：对检查清单使用 TodoWrite

**何时使用：**
- 确保技能真正被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ When you find a skill, you MUST announce: "I'm using [Skill Name]"
❌ Consider letting your partner know which skill you're using.
```

### 3. 稀缺性
**含义：** 来自时间限制或有限可用性的紧迫感。

**在技能中的作用：**
- 有时限要求：“Before proceeding”
- 顺序依赖：“Immediately after X”
- 防止拖延

**何时使用：**
- 立即验证要求
- 时间敏感工作流
- 防止“我之后再做”

**示例：**
```markdown
✅ After completing a task, 立即 request code review before proceeding.
❌ You can review code when convenient.
```

### 4. 社会认同
**含义：** 服从他人正在做或被视为正常的事情。

**在技能中的作用：**
- 普遍模式：“Every time”、“Always”
- 失败模式：“X without Y = failure”
- 建立规范

**何时使用：**
- 记录通用实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ Checklists without TodoWrite tracking = steps get skipped. Every time.
❌ Some people find TodoWrite helpful for checklists.
```

### 5. 共同体
**含义：** 共享身份、“我们感”、群体归属。

**在技能中的作用：**
- 协作语言：“our codebase”、“we're colleagues”
- 共同目标：“we both want quality”

**何时使用：**
- 协作工作流
- 建立团队文化
- 非层级实践

**示例：**
```markdown
✅ We're colleagues working together. I need your honest technical judgment.
❌ You should probably tell me if I'm wrong.
```

### 6. 互惠
**含义：** 回报已获得利益的义务。

**作用方式：**
- 谨慎使用：可能显得操纵
- 技能中很少需要

**何时避免：**
- 几乎总是避免（其他原则更有效）

### 7. 喜好
**含义：** 更愿意与喜欢的人合作。

**作用方式：**
- **不要用于遵从**
- 与诚实反馈文化冲突
- 会制造逢迎

**何时避免：**
- 强制纪律时始终避免

## 按技能类型组合原则

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 强制纪律 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指南/技术 | 适度权威 + 共同体 | 过重权威 |
| 协作 | 共同体 + 承诺 | 权威、喜好 |
| 参考 | 只要清晰 | 所有说服技巧 |

## 为什么有效：心理机制

**清晰边界规则减少合理化：**
- “你必须” 消除决策疲劳
- 绝对语言消除“这是不是例外？”问题
- 明确的反合理化条款堵住具体漏洞

**执行意图创造自动行为：**
- 清晰触发 + 必需动作 = 自动执行
- “When X, do Y” 比 “generally do Y” 更有效
- 降低遵从时的认知负荷

**LLM 具有类人响应模式：**
- 训练于包含这些模式的人类文本
- 权威语言在训练数据中常出现在遵从之前
- 承诺序列（陈述 → 行动）被频繁建模
- 社会认同模式（所有人都做 X）建立规范

## 伦理使用

**正当：**
- 确保关键实践被遵循
- 创建有效文档
- 防止可预测失败

**不正当：**
- 为个人利益操纵
- 制造虚假紧迫感
- 基于内疚迫使遵从

**测试：** 如果用户完全理解这种技巧，它是否仍服务于用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七种说服原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 N=28,000 个 LLM 对话测试 7 种原则
- 使用说服技巧后，遵从率从 33% 提升到 72%
- 权威、承诺、稀缺性最有效
- 验证 LLM 行为的类人响应模型

## 快速参考

设计技能时，问：

1. **它是什么类型？**（纪律 vs 指南 vs 参考）
2. **我试图改变什么行为？**
3. **哪些原则适用？**（纪律类通常是权威 + 承诺）
4. **我是否组合太多？**（不要七个全用）
5. **这是否合乎伦理？**（是否服务用户真实利益？）
